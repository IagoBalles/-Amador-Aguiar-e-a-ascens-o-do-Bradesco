# -Amador-Aguiar-e-a-ascens-o-do-Bradesco
Projeto utilizando o Google NotebookLM para ilustrar a ascensão do Banco Bradesco através do feitos de seu fundador
Fontes: https://www.youtube.com/watch?v=WtIaWXYMu0M ; https://museubradesco.fb.org.br/pages/capitulos/amador-aguiar.html ; https://www.youtube.com/watch?v=KqBrVmwviDo ; https://www.youtube.com/watch?v=p2Foj3F8_ps
Dentro do projeto, nota-se a velocidade que a ferramenta gera os resultados em cima das fontes, aplicando uma enorme precisao nas informacoes e sugerindo novas fontes complementares. O uso da ferramenta NotebookLM potencializa o aprendizado e o estudo devido a profundidade que pode ser alcaçada
O resultado é uma entrega de informaçoes em poucos minutos, que um humano levaria horas para compilar, e fica ainda mais facilitado com as ferramentas de video, slides e graficos geradas pelo sistema
